# 이찬식 Data Analyst Portfolio

데이터의 기준을 먼저 확인하고, 결과가 왜 그렇게 나왔는지 끝까지 추적하는 데이터 분석가를 지향합니다.

통계와 실험계획을 바탕으로 데이터를 정리하고, 분석 결과를 실제 판단에 쓸 수 있는 지표와 근거로 만드는 데 집중합니다.  
SQL 기반 KPI 분석, API와 Crontab을 활용한 데이터 수집 자동화, 시정 예측 모델 고도화, SHAP Value와 Wasserstein Distance 기반 성능 저하 원인 분석 경험이 있습니다.
