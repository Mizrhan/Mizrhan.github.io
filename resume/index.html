Profile

FP&A 인턴으로 재무·마케팅 영역의 정기 분석 업무를 데이터 파이프라인으로 전환하는 일을 맡고 있습니다. 공헌이익, 재고 소진 개월수, 수출 대금 입금확인처럼 금액이 맞아야 하는 데이터를 다루기 때문에, 결과를 산출하는 것뿐 아니라 오류를 드러내는 검증 장치와 인수인계가 가능한 문서를 함께 설계합니다. 구축한 파이프라인 하나는 평일마다 자동 실행되며, 코드와 데이터와 매뉴얼을 이관해 동료와 병행 운영하고 있습니다.

공공 데이터 분석 경진대회 3회 수상 경험을 바탕으로 데이터 분석과 인사이트 도출, 서비스 기획 역량을 쌓았습니다. 통계와 실험계획을 전공해 A/B 테스트 결과 해석, 통계적 유의성 검증, 가설검정에 익숙합니다. 또한 API와 Crontab을 활용한 실시간 데이터 수집 및 정제 자동화, ML/DL/Ensemble/Bayesian Optimization 기반 모델 고도화, SHAP, PDP, Wasserstein Distance를 활용한 성능 변동 원인 분석 경험이 있습니다.

재무·마케팅 정기 산출 업무의 파이프라인 전환

엑셀 수기 대조와 수기 피벗으로 운영되던 업무 3종을 데이터 파이프라인으로 전환했습니다. 공통으로 잡은 원칙은 오류가 예외를 발생시키지 않고 그럴듯한 숫자로 나타나는 구간을 드러낸다는 것이었고, 산출물마다 검증 자료와 인수인계 문서를 함께 냈습니다.

초기 계약 종료 시점에 연장 제안을 받아 근무 기간을 연장했습니다.

수출 거래 입금확인 자동화

  • ERP 수집 → 저장소 정합 → 8단계 판정 → 예외 건만 리포트하는 파이프라인을 구축해 평일 자동 실행 중이며, 수작업 5일 걸리던 대조를 자동 실행 약 10분과 예외 검토 약 30분으로 줄였습니다
  • 코드·데이터·판정 규칙 매뉴얼을 동료에게 인계해 각자 PC에서 병행 운영하고 있습니다
  • 한 전표에 여러 출고건이 묶이는 구조를 그룹 합계 비교로 바꿔, 행 단위로는 의미가 없던 편차(실측 +8,104%)를 판정 가능한 지표로 만들었습니다
  • 원천에서 사라진 행, 수집 누락, 미실행일을 각각 탐지하는 장치를 넣어 오류가 발생하지 않는 실패를 드러냈습니다
  • 사람이 내린 확인 결과를 저장소에 영속화해 같은 건이 다시 올라오지 않도록 했습니다

제품별 공헌이익(CM) 자동화

  • 엑셀 시트 29장 수기 집계(대상 2종)를 DuckDB 파이프라인으로 옮겨 전 품목 33종을 배치 1회로 산출합니다. 수작업 5일 걸리던 작업이 약 4분(데이터 계산 70초)이 됐습니다
  • 광고 원천 6종의 자연어 텍스트에서 제품·라인을 판정하고, 원천별 검증 자료 배포와 비용 성격 분류로 미매핑 광고비를 전체 25.2%에서 8.9%로(최대 원천 41% → 15%) 낮췄습니다
  • 매핑 규칙을 코드에서 엑셀 127행으로 분리해 실무자가 직접 편집하게 바꾸고, 교체 후 원천 텍스트 491건 전수 대조로 동일성을 확인했습니다
  • 미매핑 광고비(전체의 25.2%)를 안분하는 로직을 구현했으나 가정이 성립하지 않아 채택하지 않고, 미귀속 금액을 화면에 상시 노출했습니다
  • 환율 적용 오류를 발견·정정해 해당 원천의 원화 환산액을 약 15.6% 바로잡았습니다

재고 소진 개월수(MOC) 산출 자동화

  • 로트, 지역별 재고 스냅샷, 판매 데이터를 묶어 재고 기준 3종의 MOC를 산출하고, 수기 산출물과 684셀 전수 대조로 완전 일치를 확인했습니다. 수작업 2일 걸리던 산출이 실행 약 8초가 됐습니다
  • 기준본을 고정하는 회귀 테스트를 도입해, 로직을 고칠 때마다 산출물이 어긋나지 않는지 자동으로 검증합니다
  • 카테고리·판매명·지역 매핑 규칙을 코드가 아니라 엑셀에서 읽게 하고, 산출물을 수식 모드로 내 검토자가 셀 단위로 근거를 되짚을 수 있게 했습니다
